# HG633 Packages

Verified application packages for the maintained HG633 port. Only use packages matching the exact board and kernel identity. Device settings and radio calibration are not distributed.

Online catalog: `v1/catalog.json` and RSA/SHA256 signature `v1/catalog.sig`. Application assets are attached to versioned Releases. The router verifies the catalog and package checksums before staging an update.

The signing private key, device calibration, credentials, NAND images and personal firmware do not belong in this repository.
